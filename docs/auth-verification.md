# 認証の検証範囲

確認した動作は、旧名称SideNote AIのときの検証記録です。当時の名称と結果を残しています。

SideNoteのCodex / ChatGPT接続について、Windows上で実ログインと模擬App Serverの両方を使用して確認しています。認証情報の保存・更新はCodex CLIが管理します。

## 確認した動作

- 空の検証用プロファイルからの初回ログイン、ログアウト、再ログイン。
- 設定画面のサインイン状態・モデル一覧と、再起動後のログイン保持。
- メイン会話と付箋での実際のストリーミング回答、別Threadでの生成、Threadの再開。
- ログアウト・再ログイン前後の会話と付箋の保持。
- 模擬サーバーによる認証切れ・接続切断からの復帰、ストリーム中断、生成ロックの解除。
- ログイン待ちの再読み込み、別タブでログアウトした後の状態再取得。

実ログインの確認ではCodex CLI 0.144.4を使用しました。別バージョン・別OSや、実トークンの期限切れまで待つ更新検証はこの記録に含みません。

## 再現できる自動テスト

```sh
npm test -- tests/integration/codex.test.ts
npm run build
npm run test:e2e -- tests/e2e/settings.spec.ts
```

これらは模擬認証を使い、外部AIへの接続やログイン操作は行いません。実際の接続確認は任意の `npm run test:codex` で行えますが、ログイン済みのCodex CLIと利用枠が必要です。

実ログインを検証する場合は、普段の保存先と認証プロファイルを分けます。既存の資格情報をコピーせず、本人がブラウザでログインしてください。トークン・認証URL・実利用ログを公開文書やIssueに記録しないでください。
